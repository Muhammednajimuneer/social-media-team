## Install (2 minutes)

You need a paid Claude plan (Pro, Max, Team or Enterprise).

1. Download **social-media-team.zip** from this page. Don't unzip it.
2. In Claude, open **Settings → Capabilities** and make sure **Code execution and file creation** is on.
3. Go to **Customize → Skills**, click **+**, then **Create skill → Upload a skill**, and choose the zip.
4. Make sure the skill is switched on.

## Use it

Start a new chat and type a command, for example:

- `/post why small businesses should start using AI this year, for LinkedIn`
- `/spy` and paste a reel's transcript or screenshots
- `/voice` and paste 3 of your old posts (do this first, so everything sounds like you)

You can also just ask normally: "write me a caption for this reel".

## Good to know

- Claude never posts, comments or sends DMs for you. Platforms restrict automation, and your account matters more than a shortcut.
- /check is a quality self-check, not a promise that no AI detector will ever flag you.
- Add your own real numbers and stories. The skills will ask instead of making them up.
